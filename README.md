# 信息学体验馆

面向学生招生宣讲与兴趣课堂的单页体验馆，内容依据第二版开场叙事方案组织。

## 运行方式

直接双击 `index.html` 即可运行。项目不依赖网络、Node.js、服务器或第三方库。

## 演示内容

- AI 四级任务：解释题目、整理数据、程序计算、最优方案，教师点击逐级推进。使用预设情境内容，不联网调用模型。
- 主线介绍：信息学与 AI 的计算基础、五大学科奥赛、国家背景、CSP-J/S 与信奥成长路线、IOI 2026 中国队成绩和公开高校选拔机会。政策条件及来源可展开查看。

- 牛顿迭代法：使用固定面积 `4、6、10、13、10007`，统一从 `1 × N` 的初始猜想开始，观察矩形逐渐变成正方形。
- 校园网络布线：提供 5 个难度递增的网络案例，从 6 个节点、10 条候选网线开始，逐步增加节点和边，最后演示一个本身不连通、无法形成覆盖全部节点的最小生成树的网络；学生先猜测应该保留的边，程序再用 Kruskal 按长度排序，并跳过会形成环的网线。

## 操作方式

选择校园网络案例后，先点击提示数量的网线，再使用“程序开始布线”和“揭晓最小网络”。动画会明确展示当前检查的边、加入网络的边，以及因为成环而被跳过的边；最后一个案例还会展示“图不连通，所以无法完成”的结论。底部的“上一步”“下一步”“播放”“暂停”“重置”可以控制算法步骤。右侧 C++ 代码会和左侧动画同步高亮。

算法实验区域支持以下快捷键：← / → 切换步骤，空格播放或暂停，R 重置。阅读主线时不抢占页面滚动键。AI 与成长路线标签可用左右方向键切换。

进入牛顿实验时默认选择与开场一致的面积 13，仍可自由切换五个案例。实验中的“回到主线”定位到对应实验回顾，牛顿回顾可继续校园挑战。顶部“动态效果”可关闭装饰和过渡动画。

## 课件视频

视频最后观看。原始文件 `assets/infosci-course.mp4` 保留不变，网页优先使用 VP9 / Opus 的 `infosci-course-browser.webm`，另有无损重封装的 MP4 备用格式与封面。没有 H.264 解码支持的浏览器只提供重新加载 WebM，避免切换成只有声音的格式。

转码工具只存在于忽略的 `.tools/`，网页运行不依赖该工具。`prepare_video.py` 为本地生成脚本，不会上传视频。

右侧代码可以进入编辑模式。当前版本的编辑只改变展示内容，动画仍使用固定演示步骤；保持代码行数不变时，行号高亮会继续同步。
